# RunRave OpsSuite (Enterprise Operations Platform)

Unified warehouse and logistics management platform integrating critical fulfillment systems into a single operations hub:

- **VRM (Video Resource Management)**: Live order packing and return unboxing recording, barcode scanner integration, and AWS S3/MongoDB storage backups.
- **LMS (List Management System / Excel-Filler)**: Full-stack automated spreadsheet populator and web product enricher (CSV upload, ExcelJS template preservation, URL metadata extraction, background batch jobs, conflict review, and `.xlsx` export).
- **CMS (Claim Management System)**: Marketplace dispute filing (Meesho, Amazon, Flipkart, Courier) with 1-click video evidence linking from VRM *(Coming Soon)*.
- **RMS (Return Management System)**: Customer return triage, reverse logistics inspection, condition grading (Grade A/B/C), and restocking dispositions *(Coming Soon)*.
- **System Administration**: Role-based access control (Admin, Auditor, Operator) and centralized connectivity monitoring.
